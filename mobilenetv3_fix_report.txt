================================================================================
MobileNetV3Small INT8 Fix Report
================================================================================

PROBLEM:
--------
INT8 accuracy collapsed to 0.36% (from 99.64% FP32) — completely random predictions

ROOT CAUSE:
-----------
Wrong export script was used:
  ❌ Used: export_retrain_run6_plus2_onnx.py (for NAS EvalNetwork)
  ✓ Should use: Teacher/export_all_teacher_onnx_int8.py (for Teacher models)

This produced an architecture mismatch:
  - FP32 ONNX contained NAS EvalNetwork cells (Conv+ReLU only)
  - INT8 quantizer expected MobileNetV3 (Hardswish + SE blocks)
  - Calibration on wrong graph → garbage inference

FIX APPLIED:
------------
1. Re-exported with correct Teacher script:
   cd Teacher && python3 export_all_teacher_onnx_int8.py --models MobileNetV3Small \
     --calib-dir ../dataset_multi_distance --num-calib 200 \
     --activation-type QUInt8 --weight-type QInt8 --opset 13

2. Verified ONNX architecture:
   ✓ FP32: Conv(52), HardSigmoid(28), Mul(28), Relu(14), GAP(10)
   ✓ INT8: QDQ per-channel, QUInt8 activations, opset 13
   ✓ Smoke test: both produce valid non-degenerate logits

3. Added safety check to export_retrain_run6_plus2_onnx.py:
   Blocks Teacher model folders automatically

RESULTS:
